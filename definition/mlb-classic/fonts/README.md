# Bitmap fonts

M1 vendors the `4x6.bdf`, `5x7.bdf`, and `6x10.bdf` files from X.Org's
`font-misc-misc` 1.1.3 release:

`https://xorg.freedesktop.org/archive/individual/font/font-misc-misc-1.1.3.tar.xz`

Each selected BDF identifies itself as a public-domain font. The upstream
`COPYING` file is included verbatim and states: “Public domain font. Share and
enjoy.” No attribution or redistribution condition is imposed, so these fonts
meet LEG-03 for this M1 display definition.
