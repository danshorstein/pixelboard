# Security

The dashboard is intended for a trusted local network. Do not expose it
directly to the public internet. The six-digit device PIN protects dashboard
changes and software updates; the installer creates a unique PIN on first run.
Retrieve it on the device with the command documented in the installation
guide and change it before sharing access.

Do not include credentials, calendar subscription URLs, device backups, or
private logs in bug reports. For security issues, use GitHub's private
vulnerability reporting for this repository rather than posting details in a
public issue.
